# 🎮 Ghost 2048 👻 

A clean, responsive clone of the classic 2048 game built with Vanilla HTML, CSS, and JavaScript.  
No frameworks, no libraries. Just pure JS + mobile swipe support.

**[Play Live Demo](https://yourusername.github.io/2048-fun)**

---

## ✨ Features

- **Classic 2048 Logic**: 4x4 grid, merge tiles, reach 2048 to win
- **Mobile + Desktop**: Arrow keys, WASD, and swipe controls
- **Smooth Animations**: Tile move, spawn, and merge transitions
- **Score System**: Current score + Best score saved with `localStorage`
- **Modern UI**: Glassmorphism design + gradient background
- **Responsive**: Works perfectly on Android and Desktop
- **3-File Structure**: Clean separation of HTML, CSS, JS

---

## 🛠️ Tech Stack

- **HTML5** - Game structure
- **CSS3** - Glassmorphism, animations, responsive grid
- **Vanilla JavaScript ES6** - Game logic, DOM, localStorage
